# AI-Powered Promo Finder — Prototype

A Streamlit dashboard for exploring shortlisted screenplay promo candidates and reviewing AI-generated editorial scores.

## What this prototype does

- Loads the `candidate_shortlist.csv` generated by the local pipeline.
- Optionally loads `ai_evaluation_full.csv`.
- Shows shortlist and AI-evaluation coverage.
- Filters candidates by episode, verdict, and verified score.
- Displays candidate timestamps, scores, explanations, and screenplay text when present.

## Run locally

Python 3.10+ is recommended.

```bash
python -m venv .venv
```

Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
streamlit run app.py
```

Then upload the CSV outputs in the sidebar.

## Expected input files

- `candidate_shortlist.csv`
- `ai_evaluation_full.csv` (optional until AI evaluation is complete)

The evaluation CSV should include `candidate_id`, `hook_score`, `cliffhanger_score`, `context_score`, `emotion_score`, `verified_score`, and `verdict`. The dashboard also uses original candidate fields such as `episode`, `start_time`, `end_time`, `duration`, and `content` when available.

## Confidentiality

The supplied screenplay input pack and real screenplay-derived CSV outputs are intentionally not included in this repository. Keep the original ZIP, extracted scripts, `.env`, API keys, and any screenplay-containing outputs out of public GitHub. For evaluator access to real raw outputs, use the private Drive sharing method approved by the assignment.

## Important scope note

This repository is the **results-explorer prototype**. The parsing, candidate-generation, heuristic-shortlisting, and Gemini evaluation scripts are run locally in the separate project workspace. Copy those source scripts into this repository only after reviewing them for secrets and confidential input data if you want the public repository to include the complete pipeline.

## Limitations

- AI scores are subjective editorial assistance, not ground truth.
- Fixed-duration candidate windows are not guaranteed to be natural editorial cuts.
- Human review is required before using a candidate as a published advertisement.
- An unevaluated candidate must not be treated as AI-scored.
